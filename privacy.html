LocalDeck — Privacy Policy

Last updated: October 20, 2026

LocalDeck is a Chrome extension that replaces the new tab page with a widget dashboard and adds a popup for tab rules. It is built local-first: there is no account, no sign-up and no server operated by the developer. The extension does not collect, sell or share your personal data, and it contains no analytics, ads or tracking code.

What is stored, and where

Data Where it lives
Screen Time and productivity statistics: the domain of the active tab (for example github.com, never the full address), time spent, tab open/close counts Only on this device (chrome.storage.local)
Tab rules, cleanup settings, custom background image Only on this device
Trello and Vikunja connection details (instance address, API key, token) Only on this device; never synced
Appearance, header and widget layout settings; to-do list when no integration is connected chrome.storage.sync — Chrome's own sync, tied to your Google account. It works only if you have Chrome sync turned on, and is governed by Google's Privacy Policy.

Network requests

LocalDeck makes network requests only in these cases:

  • Bookmark and tab icons. To show favicons in the Chrome Library widget, the site address is passed to Google's public favicon service (www.google.com/s2/favicons).
  • Search. When you submit a query in the Search widget, the browser opens Google Search with that query.
  • Trello (optional). If you connect Trello, your tasks are read from and written to api.trello.com with the key and token you provide.
  • Vikunja (optional). If you connect a Vikunja instance, requests go only to the address you entered. Access to that address is requested from you at the moment you connect, and only for that host.

No data is sent to the developer.

LocalDeck is open source under the MIT license, so every statement on this page can be checked against the code: github.com/rstp-god/chrome-extension-new-tab-rstp.

Permissions

  • storage — saving your settings, widgets and statistics.
  • tabs, tabGroups — sorting, grouping and cleaning up tabs according to your rules; measuring time per domain for Screen Time.
  • bookmarks — showing your bookmarks in the Chrome Library widget.
  • idle — pausing Screen Time while you are away from the computer.
  • alarms, notifications — scheduled tab cleanup and the prompt that asks before closing tabs.
  • https://api.trello.com/* — the optional Trello integration.
  • Optional access to an https:// host — granted only when you connect your own Vikunja server, and only for that server.

Deleting your data

Removing the extension deletes everything it stored on the device. Data in Chrome sync can be cleared in Chrome settings → You and Google → Sync → Review your synced data. Disconnecting Trello or Vikunja in the To-do widget removes the stored credentials.

Changes and contact

If this policy changes, the new version is published on this page with a new date. Questions: GitHub Issues.

LocalDeck — политика конфиденциальности

Обновлено: 20 октября 2026

LocalDeck — расширение Chrome, которое заменяет новую вкладку дашбордом с виджетами и добавляет попап с правилами вкладок. Оно сделано по принципу local-first: нет аккаунта, регистрации и сервера разработчика. Расширение не собирает, не продаёт и не передаёт ваши персональные данные; в нём нет аналитики, рекламы и трекинга.

Что хранится и где

Данные Где хранятся
Статистика экранного времени и продуктивности: домен активной вкладки (например github.com, никогда не полный адрес), время, число открытых и закрытых вкладок Только на этом устройстве (chrome.storage.local)
Правила вкладок, настройки очистки, своя картинка фона Только на этом устройстве
Данные подключения Trello и Vikunja (адрес инстанса, API-ключ, токен) Только на этом устройстве, никогда не синхронизируются
Настройки внешнего вида, хедера и раскладки виджетов; список задач, если интеграция не подключена chrome.storage.sync — встроенная синхронизация Chrome через ваш Google-аккаунт. Работает, только если в Chrome включена синхронизация, и регулируется политикой Google.

Сетевые запросы

LocalDeck обращается в сеть только в этих случаях:

  • Иконки закладок и вкладок. Чтобы показать фавиконки в виджете Chrome Library, адрес сайта передаётся в публичный сервис иконок Google (www.google.com/s2/favicons).
  • Поиск. Когда вы отправляете запрос в виджете поиска, браузер открывает Google Поиск с этим запросом.
  • Trello (по желанию). Если вы подключили Trello, задачи читаются и записываются в api.trello.com с вашим ключом и токеном.
  • Vikunja (по желанию). Если вы подключили свой инстанс Vikunja, запросы идут только на указанный вами адрес. Доступ к нему запрашивается в момент подключения и только для этого хоста.

Разработчику никакие данные не отправляются.

LocalDeck — open source под лицензией MIT, поэтому каждое утверждение на этой странице можно проверить по коду: github.com/rstp-god/chrome-extension-new-tab-rstp.

Разрешения

  • storage — сохранение настроек, виджетов и статистики.
  • tabs, tabGroups — сортировка, группировка и очистка вкладок по вашим правилам; подсчёт времени по доменам для экранного времени.
  • bookmarks — показ ваших закладок в виджете Chrome Library.
  • idle — пауза экранного времени, пока вы отошли от компьютера.
  • alarms, notifications — очистка вкладок по расписанию и уведомление с вопросом перед закрытием.
  • https://api.trello.com/* — необязательная интеграция с Trello.
  • Необязательный доступ к https://-хосту — выдаётся только при подключении вашего сервера Vikunja и только для него.

Удаление данных

При удалении расширения стирается всё, что оно сохранило на устройстве. Данные в синхронизации Chrome очищаются в настройках Chrome → Вы и Google → Синхронизация → Проверить синхронизированные данные. Отключение Trello или Vikunja в виджете задач удаляет сохранённые ключи.

Изменения и контакты

Если политика изменится, новая версия появится на этой странице с новой датой. Вопросы — в GitHub Issues.
